# RAMA: plugin-guided portrait version

2026-10-02. The user explicitly added/mentioned Remotion and HyperFrames by HeyGen, asked why they were not used, and authorized another version using either after the current correction.

The initial V1 used neither framework. The subsequent square V2 used project-local Remotion before the plugin became available in this turn. The plugin-guided next version selects Remotion, loads its creation/markup/layout/Studio guidance and creates RAMA-Portrait as a separate native 9:16 composition in the same project. HyperFrames' main guidance was inspected as an alternative; its runtime/CLI was not used to author or render a result.

The plugins are local workflow/skill capabilities. The Remotion Studio additionally exposes WebMCP playback, seek and inspection tools, which were actually used. Do not call a package install, a listed capability or reading HyperFrames guidance a HyperFrames production run.

Portrait direction: one continuously transforming property object/carrier, larger video typography, a shorter 16s story about property → estimate range → assumptions → next question. It is recomposed at 1080×1920, not a crop/scale of the square V2. Square V2 remains a separate 22s MP4.

Current sources: motion-v2/src/RamaPortrait.jsx, src/index.jsx, scripts/sound.mjs, public/soundtrack-portrait.wav. Preview: http://localhost:4174/RAMA-Portrait. @remotion/media 4.0.532 is used for Audio. The isolated render runtime is pinned to 4.0.532; the loaded plugin guidance is 4.0.530.
