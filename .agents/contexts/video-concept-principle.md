# Communication concepts before video production

Recorded 2026-10-02 at the user's explicit request. This is a reusable creative principle and project context, not an installed skill, global rule or complete workflow.

Before interpreting “make a video” as a production task, establish the audience, communication problem, intended viewer understanding and desired action. Develop genuinely distinct concepts with short script sketches. Explain the job of each concept before choosing visuals, a renderer, effects, narration or component libraries.

Different concepts can be separate useful films, rather than alternatives from which the user must pick only one. A brand introduction, a buyer story and a professional use case serve different communication jobs. Confirm whether the user wants a selection or a series.

The concept should shape the script; the script should shape meaningful shots, actions, transitions, reading holds and sound. Tool research must support that process. Cloning repositories or installing components does not establish a persuasive marketing idea.

For RAMA, the user liked and requested all three concepts in video-series-plan.md. The earlier feature-summary script in marketing-script-v1.md is rejected and historical. Produce Film 1 now; preserve Films 2 and 3 as planned standalone pieces.
