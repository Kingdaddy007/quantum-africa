## Dependencies, licence and adaptation

21st.dev's Text Morph metadata lists framer-motion. The current author implementations import `motion/react`, React and a project-local `cn` utility; these source versions must not be treated as byte-identical. No production dependency added. The author's repository [LICENCE.md](https://github.com/ibelick/motion-primitives/blob/main/LICENCE.md) states MIT, copyright 2024 ibelick. That notice is retained beside the saved sources. Documentation snapshots are dated but not pinned to a repository commit.

Both examples animate from interactive React state and elapsed spring motion. Direct insertion is not evidence of reliable seekable video output. A Remotion adaptation needs values/positions driven by the composition frame, explicit text measurement/layout and deterministic timing. Animated Number also rounds values and uses runtime locale formatting; currency precision and locale should be deliberate. Test required frames out of order and inspect transition strips before declaring an adaptation successful.

21st.dev is a component catalogue and agent integration, rather than a video renderer. We read its setup information but did not run its CLI, create an API key, change global MCP configuration, use paid quota or install a component. These components are concrete candidates for the next treatment, not a claim that adding them guarantees quality.

Next decision belongs to the script/art direction in marketing-script-v1.md. Adapt a component only where it communicates that story better than the existing implementation.
